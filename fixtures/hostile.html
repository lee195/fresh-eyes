Acme is a multi-tenant orchestration substrate for distributed workloads. Each workspace is bound to an isolated namespace with its own quota envelope, and provisioning a new instance allocates a dedicated control plane shard alongside the workspace's object store. Tenancy parameters cannot be modified post-provisioning without a migration window, so review the configuration carefully before initializing. Quota adjustments propagate asynchronously and may take up to one billing cycle to reflect in the usage ledger.
